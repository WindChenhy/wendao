# 问道

文字修仙养成游戏 · 网页快速迭代版。

## 技术栈

- React 19 + TypeScript
- Vite
- Zustand
- Tailwind CSS v4

## 游戏静态数据

内容数据（灵药/种子/丹方/功法/丹药/法宝/技能/炼器/成就等）放在 `src/data/db/*.json`，由 `src/data/*.ts` 做类型加载与公式计算：

| 文件 | 内容 |
|------|------|
| `db/herbs.json` | 灵药 |
| `db/seeds.json` | 灵植种子 |
| `db/recipes.json` | 炼丹配方 |
| `db/gongfa.json` | 功法（品阶/起步境界/适用范围、售价、效果） |
| `db/items.json` | 丹药（1–9 品·丹纹）、材料、法宝（阶）、突破丹、坊市货架 |
| `db/herbs.json` | 灵药（1–9 阶） |
| `db/seeds.json` | 灵植种子（对应灵药阶） |
| `db/recipes.json` | 炼丹配方（含多纹丹） |
| `db/skills.json` | 战斗配置 + 七职业技能表 |
| `db/artifact_recipes.json` | 炼器配方、品质词条、器阁等级 |
| `db/achievements.json` | 成就表 |
| `db/events.json` | 奇遇/主题事件包（含门槛与结算） |
| `db/companion_stories.json` | 道侣结缘后长线剧情与隐藏道侣 |
| `db/gongfa_synergy.json` | 功法羁绊规则 |
| `db/sects.json` | 五宗门（加成/贡献商店/藏经阁）与十大职级表 |
| `db/enemies.json` | 历练敌人模板（阵营/强度档/掉落偏移） |
| `db/secret_realms.json` | 秘境（层数/环境加成/层奖励模板） |
| `db/sect_quests.json` | 宗门任务链（步骤与奖励） |
| `db/realms.json` | 十大境界表（层数/每层修为/突破率/寿元） |
| `db/classes.json` | 七职业（修炼/战斗倍率、标签） |
| `db/tribulation.json` | 天劫冲关方案（成功率修正/惩罚/消耗） |
| `db/codex.json` | 图鉴页描述与集齐奖励 |

调数值改 JSON 即可；逻辑（战斗引擎、突破、炼器、离线等）仍在 TS。玩家存档用浏览器 localStorage（当前 `saveVersion = 15`）。

## 开发

```bash
npm install
npm run dev      # 本地开发（Vite）
npm test         # Vitest 单元测试（node 环境）
npm run lint     # oxlint 静态检查
npm run build    # tsc -b + vite build
```

CI（GitHub Actions）在 push / PR 时自动跑 lint + test + build。

## 架构速览

- `src/data/db/*.json`：内容数据唯一事实来源；`src/data/*.ts` 做类型化加载与派生（勿两处改数）
- `src/game/`：纯函数引擎层——战斗（combatEngine）、突破与成功率（rules/breakthrough）、离线（offline）、日推进（day）、存档加密（saveCrypto）、迁移（saveMigrate 附近共享逻辑）
- `src/stores/`：Zustand 状态层，按领域拆分 slices（meta / cultivate / explore / combat / sect / abode / pet / companion / save），组合于 `useGameStore.ts`
- `src/panels/` + `src/components/`：UI 层，全部选择器式订阅 store；面板级 React.lazy 分包
- 存档格式：AES 密文（v2 信封带 SHA-256 完整性校验段，旧格式兼容），读档前经最小 schema 校验
