# 问道

文字修仙养成游戏 · 网页快速迭代版。

## 技术栈

- React 19 + TypeScript
- Vite
- Zustand
- Tailwind CSS v4

## 游戏静态数据

内容数据（灵药/种子/丹方/功法/丹药/法宝/技能/炼器/成就等）放在 `src/data/db/*.json`，由 `src/data/*.ts` 做类型加载与公式计算：

| 文件 | 内容 |
|------|------|
| `db/herbs.json` | 灵药 |
| `db/seeds.json` | 灵植种子 |
| `db/recipes.json` | 炼丹配方 |
| `db/gongfa.json` | 功法（含境界门槛、售价、效果） |
| `db/items.json` | 丹药、材料、法宝、法宝加成、突破丹、坊市货架 |
| `db/skills.json` | 战斗配置 + 七职业技能表 |
| `db/artifact_recipes.json` | 炼器配方、品质词条、器阁等级 |
| `db/achievements.json` | 成就表 |
| `db/events.json` | 奇遇/主题事件包（含门槛与结算） |
| `db/companion_stories.json` | 道侣结缘后长线剧情与隐藏道侣 |

调数值改 JSON 即可；逻辑（战斗引擎、突破、炼器、离线等）仍在 TS。玩家存档用浏览器 localStorage（当前 `saveVersion = 10`）。

## 开发

```bash
npm install
npm run dev
npm run build
```
