# v1.3 内容扩充调研简报

## 背景

《问道桃源》自 v1.0 完成品阶内容扩充后（丹药 1–9 品、灵药 1–9 阶 28 种、功法 89 部、法宝 1–9 阶 19 件、秘境 8 个、敌人模板 14 个），v1.1–v1.3 主要是系统玩法迭代，内容量未再增长。玩家从练气修到飞升（10 个大境界，约数百游戏日），中后期内容重复感明显。

## 目标

扩充 `src/data/db/` 下六类内容数据，覆盖**练气 → 飞升**全部 10 个大境界（qi / foundation / golden_core / nascent_soul / spirit_sea / void / integration / mahayana / tribulation / ascended）：

| 类别 | 现状 | 期望 |
|---|---|---|
| 功法 gongfa | 89 部 | 补齐各境界×品阶分布缺口，尤其高境界 |
| 丹药 items | 1–9 品+丹纹 | 各品阶新增功能丹（气血/灵力/解煞/突破等） |
| 灵药+种子+丹方 | 28 药/17 种/31 方 | 新增高阶灵药与对应种子、丹方 |
| 敌对势力/怪物 enemies | 14 模板 | 新增魔修/妖兽/鬼物/邪宗等各境界模板 |
| 秘境 secret_realms | 8 个 | 新增 2–4 个高境界秘境 |
| 法宝 items | 19 件 | 新增高阶法宝（攻/防/修向） |

## 关键约束

1. **数据契约**：所有数据必须符合 `src/data/*.ts` 中的 TypeScript 接口与既有 ID 命名规范（pill_/herb_/seed_/treasure_/enemy_ 等前缀）。
2. **品阶规则**（README）：功法品阶随境界收紧——元婴以下天地玄黄；元婴以上天地玄；炼虚以上天地；大乘及以上仅天阶。功法带适用范围（练气→金丹等），超范围失效。
3. **引用完整性**：丹方产物=items 中的丹药 ID；敌人掉落=存在的物品/灵药 ID；秘境引用存在的敌人模板；gongfa 羁绊的脉/系口径一致。
4. **平衡锚点**：数值（售价/效果/敌人三维/掉率）须参照同阶层既有条目的比例，不凭空拍脑袋。
5. 纯内容追加：不改类型定义、不改游戏逻辑；新增数据落地后 `npx tsc -b && npm test && npm run lint && npm run build` 必须全绿。

## 调研问题

1. 六类数据的精确 schema 与 ID/字段惯例是什么（file:line 级引用）？
2. 现有条目在各境界×品阶上的分布缺口在哪里？
3. 各阶层平衡锚点数值区间（售价/三维/效果比例）？
4. 修仙 genre 中各境界对应的经典丹药/法宝/妖兽/功法命名与设定惯例（作为命名与风味参考，需注明为 genre 通例而非仓库内出处）？
