# v1.2 灵兽系统调研报告

**访问日**：2026-09-24  
**深度**：standard（F1–F5 五路并行；无补查轮）  
**配套**：`brief.md` · `findings/F1.md`–`F5.md`

---

## 执行摘要

v1.2 灵兽应做成 **「1 只绑定 + 灵兽栏 + 等级 1 轴 + 辅助向 1 技能 + 洞府 1 岗位」** 的薄闭环，而不是宠物养成手游。获取以**机缘/赠送必得**为主、捕捉为可选支线（高成功率+软保底）；协战有效贡献压在约 **12%–22%**，属性加成 **+5%–12%**，技能不占主角回合；打工只作协助层（约主动收益 20%–30%，且 **0 修为/突破/贡献**）。明确禁止：喂养衰减、硬门槛必养、自由寻路 AI、多宠编队、IV/技能树。

---

## 1. 最小可玩闭环（综合 F1）

标杆重合的六件套：**获取绑定 1 只 → 栏位居所 → 1 条成长轴 + 命名 → 战斗 1 贡献 → 洞府 1 岗位 → 失败可恢复** [1][2]。  
《了不起的修仙模拟器》灵宠强调「只拥有一只」「帮助外门工作」「雕像重生」；星露谷宠物/动物是情感与生产双轨 [1][2]。多宠编队与技能树在标杆小体量里本就可砍 [1]。

**→ v1.2 萃取**：灵兽栏（洞府）+ 绑定 1 只 + 亲密度/等级 + 协战技 + 采集/看家岗 + 不永久死亡。

---

## 2. 获取与养成曲线（F2）

- **捕捉**是多因子几何分布 RNG，低成功率会造成长尾挫败（宝可梦 catch rate 公式与「64 球」类讨论）[3]；帕鲁捕获率工具/社区亦显示多次投掷刷概率的负担 [4]。  
- **孵化**适合放置回访，但必须**进度可见**（Egg cycle 模式）[5]。  
- **赠送/机缘**零失败、最贴「本命/师徒赐兽」叙事 [2][3]。  
- 养成安全区 **2–3 层**（等级 + 1 技能 + 1 次进阶）；Cassette Beasts 砍 IV/EV、帕鲁 v1.0 减负指向「选择组合而非刷子层数」[3][6][7]。

**→ v1.2**：主路径 **宗门/历练机缘赠送必得**；可选捕捉 **≥70% 且 ≤3 次软保底**；可留「灵兽蛋」短演出；只做等级 + 1 技能 + 1 突破。

---

## 3. 协战强度锚（F3）

危险样本：《寻道大千》灵兽独立乘区且「推图全靠灵兽」——必带化 [8]。无感样本：助战技能「有用吗」高频提问 [9]。  
D&D 兽宠约等于一个攻击位量级；Pathfinder 伙伴有「等级−3」税 [single source，外推]。

**建议锚点**（中置信，需试玩校准）：
| 项 | 建议 |
|----|------|
| 有效贡献 | 全队 **12%–22%** |
| 属性包 | **+5%～+12%**（双维合计约 +5%～10%） |
| 1 技能 | **辅助向**（小控/小盾/小奶），CD 2–3 回合 |
| 附加伤害 | ≤ **0.5–0.8** 次主角攻击；**禁止**无视防御主输出 |
| 行动 | **不占**主角回合 |

**→ v1.2**：灵兽技默认「护主/扰敌」工具技；伤害只做补伤。

---

## 4. 生产与离线（F4）

星露谷 Junimo：**0 种植 XP**、品质仍看玩家技能，且有范围/时段/天气/背包上限，效率低于玩家 [10]。修仙模拟器灵宠可帮工但强技能消耗自身成长 [1]。

**建议**：打工收益 ≈ 主动玩法 **20%–30%**；纯离线 **10%–15%**；**修为/突破/宗门贡献 = 0**（顶格 ≤10%）[11]。  
**本仓对齐**：已有离线修炼 85% + 道侣日锁代劳——灵兽**不要**与 `OFFLINE_EFFICIENCY` 叠乘，避免架空 36→128 灵田决策。

---

## 5. 失败模式（F5）— v1.2 五坑

1. **照料家务化**（tamagotchi/喂食排泄）— Digimon 差评原话 [12]  
2. **不养就卡进度**（强制基地/强制宠）— Palworld 差评 [13]  
3. **灵兽占比过大 / 数值膨胀**（寻道式主输出）[8]  
4. **自由寻路/空挥 AI**（Palworld 负面）[14]  
5. **收集/转生赌博疲劳**（Temtem Luma 百小时）[15]

## 6. Open questions

- 中文修仙向「灵兽伤害占比」缺少官方数值页；F3 区间为外推 [single source]。  
- 「桃源乡」原版仙灵系统一手页不可达，仅用「桃源深处」小萝卜等田园帮工类比 [1][2]。  
- 捕捉 ≥70% 的具体手感需 v1.2 实机调。

## 7. 对 v1.2 的可执行规格（建议）

```
灵兽栏（洞府）→ 机缘/赠送得 1 只（可命名）
  ├─ 等级（喂养可选、无衰减）→ 属性包 +5%～12%
  ├─ 1 辅助技（CD 2–3）→ 有效贡献 ~15%
  ├─ 突破 ×1
  └─ 岗位：灵田代收 / 看家（省 15%–25% 时间，不发修为）
图鉴 1 条；转生可带「本命」或道痕加成（待定，勿做赌博）
```
